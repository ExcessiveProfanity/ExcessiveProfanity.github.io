Privacy Policy

ExcessiveProfanity VOD Uploader · Effective 29 October 2026

Who uses this tool

This tool is used only by the owner of the ExcessiveProfanity YouTube channel, to upload their own videos to their own channel. It is not offered to the public, and no one else can sign in to it.

What Google data it uses

With the channel owner's permission, the tool uses the YouTube Data API to:

  • upload videos to the ExcessiveProfanity channel,
  • set their titles, descriptions and privacy settings,
  • add them to playlists on that channel, and
  • check that uploads have finished processing.

It does not read, collect or store any other Google account data, and it does not access viewers' data.

Storage

The sign-in token Google provides is stored only on the channel owner's own computer, so uploads can run on a schedule. Nothing is sent to any server other than Google's.

Sharing

No data is sold, shared with or transferred to anyone.

Revoking access

The channel owner can revoke the tool's access at any time from Google Account → Security → Third-party connections. Revoking access stops all uploads.

The tool's use of information received from Google APIs follows the Google API Services User Data Policy and the YouTube Terms of Service.

Contact

Questions about this policy can be sent to ExcessiveProfanity via the channel's YouTube or Twitch page.
