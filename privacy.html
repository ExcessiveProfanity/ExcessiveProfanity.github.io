Privacy Policy

ExcessiveProfanity VOD Uploader · Effective 29 October 2026 (updated 29 October 2026)

Who uses this tool

This tool is used only by the owner of the ExcessiveProfanity YouTube channel, to upload their own videos to their own channel. It is not offered to the public, and no one else can sign in to it.

YouTube API Services

This tool uses the YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What Google data it uses

With the channel owner's permission, the tool uses the YouTube Data API to:

  • upload videos to the ExcessiveProfanity channel,
  • set their titles, descriptions and privacy settings,
  • add them to playlists on that channel, and
  • check that uploads have finished processing.

It does not read, collect or store any other Google account data, and it does not access viewers' data.

Storage

The sign-in token Google provides is stored only on the channel owner's own computer, so uploads can run on a schedule. The only YouTube data the tool keeps is the IDs of the videos and playlist entries it created, so it never uploads the same video twice. Nothing is sent to any server other than Google's. The tool uses no cookies.

Data retention and deletion

  • Revoking access (below) or running the tool's revoke command (youtube-revoke) deletes the stored sign-in token immediately.
  • The stored video and playlist IDs are deleted within 30 days of access being revoked, or sooner on request.
  • To request deletion of any data, contact ExcessiveProfanity (see Contact below). Requests are handled within 7 days.

Sharing

No data is sold, shared with or transferred to anyone.

Revoking access

The channel owner can revoke the tool's access at any time, either from within the tool (youtube-revoke, which calls Google's OAuth revocation endpoint) or from the Google security settings page (Google Account → Security → Your connections to third-party apps & services). Revoking access stops all uploads.

The tool's use of information received from Google APIs follows the Google API Services User Data Policy and the YouTube Terms of Service.

Contact

Questions about this policy can be sent to ExcessiveProfanity via the channel's YouTube or Twitch page.
