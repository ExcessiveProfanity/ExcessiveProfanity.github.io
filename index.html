ExcessiveProfanity VOD Uploader

This is a private tool used by the streamer ExcessiveProfanity to publish their own past Twitch broadcasts to their own YouTube channel.

It runs on the streamer's own computer. It adds the stream's chat to each recording, removes break screens, and uploads the finished video to the ExcessiveProfanity YouTube channel on a schedule. It does not use or access anyone else's account or data.

The tool signs in to YouTube only with the channel owner's permission, using Google's standard sign-in. It uses the YouTube Data API to upload videos and add them to playlists on that channel.
